# Asteroids

Браузерная аркада на React, TypeScript и Canvas 2D.

## Запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:8080/.

## Управление

- Стрелки влево/вправо или A/D — поворот.
- Стрелка вверх или W — тяга.
- Пробел — стрельба, можно удерживать.
- Esc — пауза и продолжение; Enter — старт или повторная игра.
- Экранные кнопки поддерживают мышь и несколько одновременных касаний.
- В верхней панели — пауза, звук и полный экран.

## Правила

Три жизни. Большие астероиды распадаются на два средних, средние — на два малых.
Очки за астероиды: 20 / 50 / 100. Тарелки стреляют; большая даёт 200 очков,
малая — 1000. По мере прохождения волн увеличиваются число и скорость камней,
частота появления тарелок и их стрельбы. Параметры имеют верхние ограничения.

Нагревается только оружие: +10 за выстрел, охлаждение 20 единиц в секунду.
При 100 стрельба блокируется до охлаждения до 30. Движение не блокируется,
урон от температуры не увеличивается.

Скорость корабля ограничена 190 единицами в секунду. После отпускания тяги
он плавно тормозит. Canvas рисуется в фактическом разрешении окна с учётом devicePixelRatio до 2.
Поле подстраивается под пропорции окна и полного экрана без пустых боковых зон.
При изменении размера сохраняются прогресс и относительные позиции объектов,
а размеры фигур и скорость симуляции остаются прежними.

Потеря фокуса или скрытие вкладки ставит игру на паузу и сбрасывает кнопки.
Рекорд сохраняется локально, если браузер разрешает localStorage.

## Проверки и сборка

```sh
npm run test:run
npm run typecheck
npm run lint
npm run format:check
npm run build
```

`npm run build` создаёт сборку в `dist/` с исходной конфигурацией шаблона.
Для production-варианта: `npm run build -- --mode production --devtool false`.

## Структура

- `src/game/engine.ts` — симуляция, столкновения, волны, тарелки и очки.
- `src/game/config.ts` — баланс и параметры движения, нагрева и стрельбы.
- `src/game/input.ts` — независимые источники ввода.
- `src/game/weapon.ts` — перегрев и восстановление стрельбы.
- `src/game/renderer.ts`, `surface.ts` — отрисовка и разрешение Canvas.
- `src/game/audio.ts` — синтез звуков средствами Web Audio.
- `src/components/App/` — интерфейс, игровой цикл и обработка браузерных событий.

Визуальные элементы рисуются кодом, звуки синтезируются. Внешние изображения,
аудиофайлы и шрифты не используются. Основа окружения — официальный шаблон
Intern_JavaScript из задания, Webpack не заменён. Подробный план и результаты
проверки находятся в `docs/`.

Репозиторий: https://github.com/exsyyy/safeboard-test.

## Музыка и фон

Фоновая композиция собственного сочинения синтезируется в Web Audio: тихие
низкие аккорды с плавным появлением и затуханием, без ударных и яркого арпеджио. Сторонние композиции, записи и сэмплы не используются.
Музыка запускается после начала игры, останавливается на паузе и при проигрыше,
отключается общей кнопкой звука. Фон — почти чёрное пространство со звёздами, без сетки.

Пули игрока и тарелок исчезают при достижении края поля, не переносятся
на противоположную сторону и не попадают в цели через границу.
