# Asteroids

Браузерная ретро-аркада: управляйте кораблём, разбивайте астероиды и сбивайте
летающие тарелки. За уничтоженные цели начисляются очки. Новые волны постепенно
усложняют игру. После потери трёх жизней показывается итоговый счёт.

Главное дополнение к классической механике — перегрев оружия. Выстрелы нагревают
ствол, а паузы между очередями его охлаждают. При полном перегреве стрельба
временно отключается, но двигаться и поворачивать корабль можно всегда.

## Запуск

Нужны Node.js и npm. Проект проверен на Node.js 24.

```sh
npm ci
npm run dev
```

Открыть http://localhost:8080/.

## Управление

| Действие | Клавиши |
| --- | --- |
| Поворот | ← / → или A / D |
| Тяга | ↑ или W |
| Стрельба | Пробел, можно удерживать |
| Пауза и продолжение | Esc |
| Начало или повторная игра | Enter |

Те же действия доступны экранными кнопками для мыши и тача. Кнопки можно
удерживать; для сенсорного экрана поддерживаются одновременные нажатия.
В верхней панели находятся пауза, отключение звука и полноэкранный режим.

## Особенности

- Большие астероиды распадаются на средние, средние — на малые.
- Очки за астероиды: 20, 50 и 100; за большую и малую тарелки: 200 и 1000.
- Пули игрока и тарелок исчезают у края поля, корабль и астероиды переходят через края.
- Оружие нагревается на 10 за выстрел и охлаждается на 20 в секунду.
  При нагреве до 100 оно блокируется до охлаждения до 30.
- После отпускания тяги корабль плавно замедляется.
- Потеря фокуса или скрытие вкладки ставит игру на паузу.
- Рекорд сохраняется в браузере, если доступен localStorage.
- Спокойная фоновая музыка и эффекты синтезируются через Web Audio.
  Сторонние треки и сэмплы не используются. Звук начинается после запуска игры.

## Проверки и сборка

```sh
npm run test:run
npm run typecheck
npm run lint
npm run format:check
npm run build
```

Готовая production-сборка появляется в `dist/`. Её нужно открыть через HTTP-сервер,
а не двойным щелчком по HTML-файлу. Например, после сборки:

```sh
npx --no-install webpack serve --mode production
```

Тесты основных механик находятся в одном файле: `src/game/game.test.ts`.

## Стек и настройки

React 17, TypeScript, Canvas 2D, Webpack 5, Less/CSS Modules, ESLint, Prettier и Vitest.
Проект основан на предоставленном шаблоне Intern_JavaScript.

- `src/game/config.ts` — параметры движения, стрельбы, нагрева и очков.
- `src/game/engine.ts` — игровой процесс, столкновения, тарелки и волны.
- `src/game/renderer.ts` и `starfield.ts` — отрисовка игры и космического фона.
- `src/game/audio.ts` и `music.ts` — эффекты и фоновая музыка.
- `src/game/input.ts` — состояние клавиатурного и экранного ввода.
- `src/game/surface.ts` и `viewport.ts` — разрешение Canvas и размер поля.
- `src/components/App/` — экраны, игровой цикл и интерфейс.

Графика рисуется кодом; внешние картинки и шрифты не загружаются.
