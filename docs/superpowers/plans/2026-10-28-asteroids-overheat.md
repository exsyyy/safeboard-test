# Asteroids с перегревом оружия Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать законченную браузерную Asteroids с классическим управлением, астероидами, стреляющими тарелками, счётом, постепенным усложнением и перегревом только оружия.

**Architecture:** Чистая игровая логика на TypeScript, отрисовка через Canvas 2D и цикл requestAnimationFrame. React управляет меню, HUD и экранными кнопками. Игровые объекты не хранятся в React state с обновлением на каждом кадре.

**Tech Stack:** Существующий шаблон React 17, TypeScript 5.5.4, Webpack 5, Less/CSS Modules, ESLint и Prettier. Для тестов логики добавить совместимый с проектом Vitest, не заменяя Webpack.

**Spec:** Разделы «Цели и границы» и «Предлагаемые правила» этого документа составляют спецификацию. Предлагаемые значения не являются ранее согласованными требованиями и подлежат настройке после игрового прогона.

## Цели и границы

- Корабль поворачивается, получает тягу вперёд, движется по инерции и переходит через границы экрана.
- Стрельба вперёд по направлению корабля. Пули имеют ограниченное время жизни.
- Большие астероиды распадаются на средние, средние — на малые, малые уничтожаются.
- Тарелки появляются периодически и стреляют; столкновения и попадания наносят урон.
- Есть очки, жизни, волны, стартовый экран, пауза и экран проигрыша с результатом и повторным запуском.
- Рост сложности через количество и скорость астероидов, частоту появления тарелок и их выстрелов. Значения имеют верхние пределы.
- Единственная новая боевая механика — перегрев оружия. Температура не влияет на урон, поворот, тягу или инерцию.
- Сохранить клавиатурное управление и реализовать экранные кнопки для мыши и тача.
- В MVP не входят дуэли, парирование, направленные удары, десять фиксированных уровней, сбор ресурсов, орбитальные обломки, мультиплеер и 3D.

## Предлагаемые правила

- Управление: стрелки влево/вправо — поворот, вверх — тяга, пробел — стрельба; Escape — пауза. Экранные кнопки повторяют эти действия, не вводя наведение мышью.
- Начальные жизни: 3. После возрождения — короткая неуязвимость с визуальным обозначением.
- Температура оружия: 0–100; выстрел добавляет 10 единиц, пассивное охлаждение — 20 единиц в секунду, интервал стрельбы — 160 мс. Это стартовые параметры балансировки.
- При достижении 100 оружие блокируется до охлаждения до 30. Последний допустимый выстрел выполняется, заблокированная стрельба не создаёт пули и не добавляет нагрев.
- Начислять очки один раз за уничтоженный объект. Начальная таблица: большой астероид — 20, средний — 50, малый — 100, большая тарелка — 200, малая — 1000.
- Следующая волна начинается после уничтожения астероидов с короткой передышкой; тарелки сами по себе не задерживают переход волны.
- Ретро-графика с хорошо читаемыми силуэтами, вспышками и короткими эффектами. Точные палитра и степень пикселизации выбираются при оформлении.

## Review Focus

- Потеря фокуса и скрытая вкладка: пауза и сброс удерживаемых кнопок, без внезапного урона при возврате.
- Задержки кадров: ограничение накопленного времени, стабильное движение и охлаждение.
- Попадания: один объект не начисляет очки и не снимает несколько жизней повторно за один шаг.
- Мышь и тач: одновременные тяга, поворот и стрельба; pointercancel не оставляет кнопку зажатой.
- Перезапуск и изменение размера: нет второго игрового цикла, старых пуль, слушателей или сброшенного из-за resize прогресса.

## Файлы и интерфейсы

- `src/game/types.ts` — `Vec2`, `InputState`, `GameState`, типы корабля, астероидов, тарелок и пуль.
- `src/game/config.ts` — типизированные параметры движения, оружия, перегрева, очков и сложности.
- `src/game/engine.ts` — `createGame(config: GameConfig, seed: number): GameState` и `stepGame(state: GameState, input: InputState, dtSeconds: number): GameState`.
- `src/game/collisions.ts` — геометрия столкновений и обработка переходов через края.
- `src/game/renderer.ts` — `renderGame(ctx: CanvasRenderingContext2D, state: GameState): void`.
- `src/game/input.ts` — единое состояние удерживаемых действий для клавиатуры и экранных кнопок; `reset()` и `dispose()`.
- `src/components/Game/` — Canvas, цикл кадров, resize и связывание input/engine/renderer.
- `src/components/Hud/`, `src/components/Controls/`, `src/components/Screens/` — индикаторы, экранные кнопки и меню.
- `src/components/App/App.tsx` и `.module.less` — композиция приложения вместо Hello world.
- `src/game/*.test.ts`, `vitest.config.ts`, `package.json` — воспроизводимые тесты логики и команды запуска.
