# Результат реализации Asteroids

План: docs/superpowers/plans/2026-10-28-asteroids-overheat.md.
Дата: 29 октября 2026 года.

Реализованы корабль, инерционное движение, стрельба, астероиды трёх размеров,
их распад и столкновения, очки, жизни, тарелки со стрельбой, волны и рост сложности.
Реализованы старт, проигрыш, пауза, повторный запуск, локальный рекорд, звуки,
клавиатурные и экранные кнопки с Pointer Events.

После пользовательского прогона внесены изменения:
- Максимальная скорость 190 вместо 340, ускорение 180 вместо 230.
- Поворот 3.5 вместо 4.2 радиан в секунду; после отпускания тяги скорость
  затухает экспоненциально с коэффициентом 2.1 в секунду.
- Убраны слоганы, внешний промоблок, инструкции под полем, декоративные подписи
  и футер. Оставлены игра, показатели и управление.
- Canvas получает размер в физических пикселях с учётом плотности до 2.
  При изменении окна поле адаптируется без растягивания объектов и сброса партии.
- Перегрев блокирует только оружие; усиления выстрелов от нагрева нет.

Проверки:
- 26 автоматических тестов на движение, торможение, нагрев, распад, очки,
  столкновения через границы, волны, ограничения сложности, ввод и resize.
- npm run typecheck, lint, format:check, build проходят.
- В браузере проверены старт, экранная стрельба удержанием, рост счёта,
  перегрев, проигрыш, повторная игра, клавиатурный ввод и пауза.
- Проверено изменение буфера Canvas при полном экране и учёт devicePixelRatio.
- Физическое мобильное устройство не использовалось.

Независимый просмотр кода выявил исправленные дефекты:
- Безопасность появления новой волны должна учитывать переход через границы.
  Добавлен падавший до исправления тест с seed 13.
- Escape должен обрабатываться до проверки фокуса на кнопках.
  Проверен сценарий экранная пауза → Escape → продолжение.

Решения исполнения:
- Работа выполнена последовательно в ветке feat/asteroids-overheat в существующем
  открытом проекте WebStorm, без второго checkout.
- Компоненты управления и экранов оставлены в App; физика, отрисовка, ввод,
  звук, перегрев и адаптация поля выделены в независимые модули.
- Canvas сохраняет явный порядок рисования, для единственной функции рендера
  локально отключён лимит количества операторов с пояснением.
- Вместо нескольких промежуточных коммитов подготовлен один законченный коммит,
  включающий исправления по пользовательскому игровому прогону.
- ZIP подготовлен под нейтральным именем safeboard-test.zip; отправка задания
  на сторонний сайт не выполнялась.

При сужении поля корабль получает не менее 1.5 секунды защиты от столкновений,
чтобы изменение геометрии окна не снимало жизнь. Сценарий покрыт регрессионным тестом.
